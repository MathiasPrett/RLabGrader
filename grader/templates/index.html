Configuración

Se guarda en el archivo .env de esta carpeta, solo en tu computador. Las claves guardadas nunca se muestran: para cambiar una, escribe la nueva.

  1. Entra a Canvas en el navegador.
  2. Haz clic en tu foto o en Cuenta (barra izquierda) y luego en Configuración.
  3. Baja hasta Integraciones aprobadas y presiona + Nuevo token de acceso.
  4. En "Propósito" escribe RLabGrader y pon una fecha de expiración (por ejemplo, el fin del semestre).
  5. Presiona Generar token, cópialo y pégalo aquí. Canvas lo muestra una sola vez.

El token tiene tus mismos permisos en Canvas: no lo compartas. Si crees que alguien lo vio, elimínalo en esa misma página y crea otro.

Entra al curso en Canvas y mira la dirección en el navegador: …/courses/106099. Es ese número.

opcional, para la sugerencia IA
  1. Entra a console.groq.com y crea una cuenta (puedes usar Google o GitHub).
  2. En el menú, ve a API Keys y presiona Create API Key.
  3. Ponle un nombre (ej. RLabGrader), copia la clave (empieza con gsk_) y pégala aquí. Se muestra una sola vez.

La cuenta gratuita permite aprox. una sugerencia de taller por minuto; la app espera sola cuando hace falta.

  1. Entra a aistudio.google.com/apikey con tu cuenta de Google.
  2. Presiona Create API key y elige el proyecto de Google Cloud donde tienes los créditos.
  3. Copia la clave (empieza con AIza o AQ.) y pégala aquí.

Lo que uses se descuenta de los créditos o la facturación de ese proyecto.

Opciones avanzadas
Solo cámbiala si tu Canvas no es el de la UC.

Estadísticas por pregunta

Todos los alumnos de la planilla. "Correctas" compara con la clave actual de Canvas. Si muchos alumnos coinciden en un mismo valor distinto a la clave, la pauta podría estar mal.
